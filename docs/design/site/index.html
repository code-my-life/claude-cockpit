Know who needs you, answer in one gesture

Four steps, no admin rights

  1. 01 Download

    Get claude-cockpit-setup.exe from the latest release. Check it against SHA256SUMS.txt with Get-FileHash.

  2. 02 Run it

    The installer is not signed yet: on SmartScreen, choose More info, then Run anyway.

  3. 03 Allow the mod

    The wizard shows the line it adds to the env block of settings.json (CLAUDE_CODE_PLUGIN_DIRS) and writes it after your click.

  4. 04 Restart Claude Desktop

    Each conversation loads the mod when it starts.

Uninstall
Remove the line from settings.json, then uninstall from Windows Settings

Rarity is earned in the cockpit

How rarity is scored

Cockpit rule

Each conversation gets a score from 0 to 1. Each part counts up to its cap, then stops growing.

Active time
40 %, full at 4 hours of work
Messages
25 %, full at 60 messages
Tools run
15 %, full at 200 tool calls
Files changed
10 %, full at 40 files
Reply combo
10 %, full at 10 quick replies in a row

Uncommon from 0.25, rare from 0.5, mythic from 0.8.
